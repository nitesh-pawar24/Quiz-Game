# Quiz Game 🎮

**Quiz Game** is a single-player, category-based quiz web app built with **React**.  
It features a clean UI with animated background support, timed questions (progress-bar timer), score tracking and history, and localStorage-backed persistence.

Live demo: https://quiz-game-mu-sage.vercel.app/

---

## 🧩 Features

- Category selection: Cricket, Football, GK, Geography, History.
- Multiple-choice questions with instant feedback (correct/incorrect).
- Per-question countdown timer with a visual progress bar (color transitions from green → yellow → red).
- Randomized question order (shuffle).
- Score tracking and score history stored in `localStorage` (keeps last 5 results).
- Responsive, modern UI with glassy/rounded buttons and animated background options.
- Easy to extend: questions are kept in a `questions.js` file (JSON-like objects) so adding more content is trivial.
